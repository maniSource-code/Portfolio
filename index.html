About Me

I am a dedicated and self-motivated DevOps enthusiast with a strong foundation in Linux system administration and cloud computing using AWS. I have hands-on experience setting up production-style Linux servers, configuring web servers like Nginx, managing users and permissions, implementing firewall rules, and automating tasks using Bash scripting and cron jobs. I am passionate about learning modern DevOps tools and cloud-native technologies while strengthening my problem-solving skills.


My goal is to contribute to teams that value automation, scalability, and efficient infrastructure management while continuing to grow as a DevOps engineer.
